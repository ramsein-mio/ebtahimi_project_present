# پردیس — ویرایشگر JSON به ارائه

یک frontend مستقل برای ساخت و ویرایش ارائه در مرورگر. داشبورد و ورودی JSON فارسی و راست‌به‌چپ هستند؛ فضای حرفه‌ای ویرایش ارائه طبق نیاز محصول کاملاً انگلیسی و چپ‌به‌راست است و خود اسلایدها همچنان محتوای فارسی، انگلیسی و چندزبانه را نمایش می‌دهند. ذخیره‌سازی فقط در `localStorage` انجام می‌شود.

## اجرا

پیش‌نیاز: Node.js 20 یا جدیدتر.

```bash
npm install
npm run dev
```

سپس نشانی نمایش‌داده‌شده توسط Vite را باز کنید. ساخت نسخهٔ production و اجرای آزمون‌ها:

```bash
npm run typecheck
npm test
npm run build
npm run test:browser
npm run preview
```

## جریان کاری

1. در داشبورد «ارائهٔ جدید» را انتخاب کنید.
2. JSON مرجع شامل `presentation` و `slides` را وارد یا فایل JSON را import کنید.
3. اسلایدها با `order` مرتب، به مدل واقعی `@web-ppt/core` تبدیل و همگی با `renderSlideToSvg` آزمایش می‌شوند.
4. ارائه در `localStorage` ساخته و در ادیتور باز می‌شود.
5. در workspace انگلیسی، اسلایدها را مدیریت و عناصر را روی canvas انتخاب، جابه‌جا یا resize کنید.
6. تغییر متن، قالب، شکل، تصویر، پس‌زمینه، ترتیب لایه و موقعیت با فرمان‌های واقعی `@web-ppt/edit-core` در مدل ثبت می‌شود.
7. speaker notes برای هر اسلاید نگه داشته می‌شوند و autosave یا دکمهٔ Save، projection فعلی مدل را ذخیره می‌کند.
8. ارائه از داشبورد قابل بازگشایی و ادامهٔ ویرایش است.

نمونهٔ معتبر داخل برنامه از قرارداد زیر استفاده می‌کند:

```json
{
  "presentation": {
    "title": "عنوان ارائه"
  },
  "slides": [
    {
      "id": "cover",
      "order": 1,
      "section": "Introduction",
      "layout": "title",
      "title": "عنوان ==برجسته==",
      "subtitle": "زیرعنوان",
      "body": {
        "lead": "متن اصلی",
        "emphasis": "==!جمع‌بندی!=="
      }
    }
  ]
}
```

در اسلایدهای محتوایی، `body.bullets` آرایه‌ای از رشته‌ها یا اشیای `{ "text": "...", "details": "..." }` است. شش visual پشتیبانی‌شده عبارت‌اند از `icon-list`، `bar-chart`، `line-chart`، `pie-chart`، `comparison-grid` و `table`. نشانه‌گذاری‌های `==متن==`، `==!متن!==` و `**متن**` نیز به‌ترتیب به highlight و bold واقعی تبدیل می‌شوند. `details` هم در speaker notes همان اسلاید نگه‌داری می‌شود و هم با کلیک روی خط در حالت پرزنت داخل دیالوگ نمایش داده می‌شود. ورودی native قدیمی `web-ppt` نیز برای سازگاری فایل‌های موجود همچنان پذیرفته می‌شود.

## قابلیت‌ها و مرزها

- داشبورد، جست‌وجو، تغییر نام، انتقال به حذف‌شده‌ها، بازگردانی و حذف همیشگی فعال‌اند.
- import و اعتبارسنجی JSON، رندر SVG، thumbnailهای زنده، انتخاب و drag-and-drop اسلاید و نمایش تمام‌صفحه فعال‌اند.
- در حالت پرزنت، قرارگرفتن نشانگر روی خط آن را برجسته و محتوای اطراف را محو می‌کند؛ خط‌های دارای `details` با کلیک دیالوگ توضیحات را باز می‌کنند.
- فونت‌های محلی Vazirmatn، IRANSansX/IRANSans (fallback سازگار)، Inter، JetBrains Mono و MAD Social در bundle قرار دارند؛ گزینه‌های سیستمی سورس نمونه نیز در انتخابگر فونت موجودند.
- ساخت، تکثیر، حذف و جابه‌جایی اسلاید، speaker notes و پس‌زمینهٔ اسلاید فعال‌اند.
- متن‌های مجاز با مدل headless رسمی ویرایش می‌شوند؛ ویرایش مستقیم/پنلی، undo/redo، فونت، اندازه، رنگ، ضخامت، حالت مورب، زیرخط، فاصلهٔ خطوط و تراز فعال‌اند.
- انتخاب، جابه‌جایی، resize، حذف، هم‌ترازی و تغییر ترتیب لایهٔ عناصر فعال است؛ شکل، خط، text box و تصویر نیز قابل افزودن‌اند.
- autosave با وضعیت Saving/Saved و ذخیرهٔ دستی فعال است. تصویرهای افزوده‌شده برای بازگشایی محلی به data URL تبدیل می‌شوند.
- آزمون مرورگر، جریان JSON → ویرایش متن/موقعیت/یادداشت → تکثیر اسلاید → ذخیره → بازگشایی را در اندازهٔ desktop و mobile بررسی می‌کند.
- دادهٔ ارائه و تغییرات در همان مرورگر ذخیره می‌شوند؛ backend، حساب کاربری یا همگام‌سازی ابری وجود ندارد.
- این نسخه JSON مرجع را به مدل یکپارچهٔ `web-ppt` تبدیل می‌کند؛ فایل `.pptx` یا `.ppt` مستقیماً از این صفحه import نمی‌شود.
- برای JSON با `source: "pptx"` که metadata و anchorهای ویرایش را ندارد، `edit-core` بعضی عناصر را خواندنی تشخیص می‌دهد. برنامه این محدودیت را صادقانه در پنل ویژگی‌ها نشان می‌دهد.
- فرمان native ساخت اسلاید و notes در `edit-core` به package واقعی OOXML نیاز دارد. برای JSON خام، برنامه با حفظ schema یک projection تازه می‌سازد؛ به همین دلیل ساخت/تکثیر اسلاید خام، history همان نشست را بازنشانی می‌کند. multi-selection، grouping و crop تصویر هنوز پیاده‌سازی نشده‌اند.
- بسته‌های منتشرشدهٔ سازگار `@web-ppt/core` و `@web-ppt/edit-core` در نسخهٔ `0.5.0-beta.2` استفاده شده‌اند. سورس فعلی مخزن جلوتر است، اما نسخهٔ متناظر `edit-core@0.5.0-beta.6` هنگام ساخت این پروژه در npm منتشر نشده بود.

## Cloudflare Worker

فایل [`cloudflare-worker.js`](./cloudflare-worker.js) عیناً و مستقل از frontend نگه داشته شده است. این فایل یک HTTP relay مخصوص runtime کلادفلر است و بخشی از bundle مرورگر یا منطق تولید اسلاید نیست. توابع `fetch`، `Headers` و environment bindings آن باید در Cloudflare Workers اجرا شوند؛ frontend برای تبدیل JSON به ارائه از آن استفاده نمی‌کند.

## انتشار روی Cloudflare Workers

این پروژه با `wrangler.jsonc` برای انتشار مستقیم Vite build روی Cloudflare Workers Static Assets پیکربندی شده است. راهنمای گام‌به‌گام را در [CLOUDFLARE_DEPLOY.md](./CLOUDFLARE_DEPLOY.md) ببینید.

دستورهای سریع:

```bash
npm ci
npm test
npm run cf:dev       # پیش‌نمایش محلی با Wrangler
npm run cf:deploy    # build و انتشار روی Cloudflare
```

انتشار، نسخه frontend را منتشر می‌کند؛ قابلیت ذخیره‌سازی فعلی همچنان localStorage مرورگر است و شامل backend یا همگام‌سازی ابری نیست.
