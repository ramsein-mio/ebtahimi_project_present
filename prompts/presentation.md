# Presentation-generation prompt

Follow `shared-json-contract.md` exactly. Output one valid JSON object only, with no Markdown fences or commentary.

Create a coherent, presentation-ready deck for the user's topic and audience. Prioritize clear narrative, strong slide titles, concise but meaningful body text, evidence-based claims, and varied layouts. Use charts, tables, comparison grids, and shape compositions only when they improve comprehension. Keep theme, backgrounds, chart series colors, and visual styling in the shared render fields. Do not create a custom JSON structure or add undocumented keys.

All required metadata and slide fields must be present. Keep IDs unique, ordering sequential, recap references valid, and use supported visual types only.
